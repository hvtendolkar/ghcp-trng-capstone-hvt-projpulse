## 🎯 We Have a Governance Framework

Starting **October 1, 2026**, all code merged to main must comply with ProjectPulse AI's governance framework.

**What does this mean for you?**
- ✅ All PRs must reference which governance principles they involve
- ✅ Code reviewers verify governance compliance (using checklist)
- ✅ Non-compliant code gets fixed before merge
- ✅ Monthly compliance audits track progress

**Why now?**
ProjectPulse AI manages Big 4 portfolio data that must be:
- Accurate (financial transactions)
- Explainable (AI-driven insights)
- Reliable (system architecture)
- Tested (code quality)

Governance ensures all of this.

---

## 📚 The 4 Core Principles

### I. AI-Driven Financial Intelligence
AI insights must be **transparent, validated, auditable, configurable**

### II. Financial Data Integrity & Compliance
Financial data must be **precise, single-source, auditable, reconciled**

### III. Scalable API-First Architecture
Architecture must be **documented, backward-compatible, modular, integral**

### IV. Test-Driven Development & Quality Gates
Code must be **tested (80%+ coverage), reviewed, deployable**

Each principle has specific requirements documented in guides for your role.

## ❓ FAQ

**Q: Is this required?**
A: Yes. Starting Oct 1, governance applies to all code merged to main.

**Q: What if my PR violates governance?**
A: Reviewer requests changes, you fix, then merge. It's a learning process.

**Q: How do I know if I'm complying?**
A: Use the [Pre-PR Checklist](docs/governance/developer-pre-pr-checklist.md) before submitting. Reviewers verify compliance.

**Q: What if I don't understand a principle?**
A: Read your role guide or the [FAQ](docs/governance/FAQ.md). Ask Tech Lead if stuck.

**Q: Can governance change?**
A: Yes! Use the [Amendment Process](docs/governance/amendment-process.md) to propose changes.

**Q: How will adoption be tracked?**
A: [Governance Acknowledgment Form](docs/governance/governance-acknowledgment-form.md) tracks who understands governance. Target: 100% by Oct 28.
